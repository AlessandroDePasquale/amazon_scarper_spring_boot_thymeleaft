## 📖 Descrizione

**AmazRaper** è un'applicazione Java *standalone* ideata per monitorare in modo semplice ed efficace il prezzo dei tuoi prodotti preferiti su **Amazon.it**. 

L'applicazione è progettata per essere immediata: non richiede installazioni complesse o configurazioni di ambiente. Basta avere installato Java (versione 21 o superiore) e fare doppio click sul file `.jar` per iniziare subito a tracciare le tue offerte.

---

## ✨ Caratteristiche Principali

- 🇮🇹 **Supporto Amazon.it**: Monitoraggio accurato dei prezzi sullo store italiano.
- 🫙 **Applicazione Standalone**: Nessun server esterno necessario, funziona direttamente sul tuo PC.
- ⚡ **Semplicità d'uso**: Avvio rapido tramite semplice doppio click.
